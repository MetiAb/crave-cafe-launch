Crave Cafe
A modern, responsive restaurant website for Crave Cafe, designed to provide customers with an easy way to explore the restaurant, view its menu, learn about the restaurant, find its location, and get in touch.
Features
Responsive design for desktop, tablet, and mobile
Restaurant information and introduction
Interactive food menu
Food and restaurant image gallery
Opening hours
Location and directions
Contact information
Social media links
Customer reviews and ratings
Reservation interface
Modern restaurant-focused user interface


Technology
This project is built using:
React
Vite
Tailwind CSS
Supabase
JavaScript/TypeScript
Git and GitHub

Running the Project Locally
Requirements
Make sure you have:
Node.js
npm
Git

Installation
Clone the repository:
git clone https://github.com/MetiAb/crave-cafe-launch.git
Enter the project directory:
cd crave-cafe-launch
Install the dependencies:
npm install
Start the development server:
npm run dev
The website will then be available at the local development address shown in your terminal.
Environment Variables
If the project uses Supabase or other external services, create a .env file in the project root and add the required environment variables.
Do not commit private API keys, passwords, or other sensitive credentials to GitHub.
Building for Production
To create a production build:
npm run build
To preview the production build locally:
npm run preview
Deployment
The project can be deployed using a hosting provider that supports Vite/React applications.
The production deployment should be connected to the GitHub repository so that updates can be deployed whenever changes are pushed to the main branch.
Reservations
The website includes a reservation interface designed to allow customers to request a table.
The reservation system can be connected to the project's backend services to store reservation requests and send notifications to the restaurant.
